Aresys Formats Input/Output

Aresys IO is the official Python package for reading, writing and work with Aresys formats.

The supported internal formats are:

Product Folder

Point Target Binary

SAR System

Each module is designed to be modular, independent and extensible, allowing users to adopt only the functionalities they need.

Tutorials

Each section of the documentation provides detailed usage guides and examples for the main features. Quickstart guides are also available to help you get started with the package. Just run the code provided in your terminal and follow the instructions!

Getting Started

This package can be installed using pip in any python environment satisfying the requirements.

Refer to the installation documentation for further information.

aresys io product folder sarsystem point target binary product format python simulation e2e
