Functions

Read

Read satellite acquisition data and returns a SatTable instance.

Parameters:

Name Type Description Default
sar_system_folder_name Path | str

directory containing the SAR system data, including acquisition modes and swaths.

 required
acq_mode_id str

The acquisition mode identifier, used to locate the corresponding TimelineTable.xml and determine the beam information.

 required

Returns:

Type Description
SatTable

An instance of the SatTable class that contains the following fields: - timeline_table : TimeLineTable An instance of the TimeLineTable class. - swath_table : dict A dictionary mapping each beam name to its corresponding SwathTable instance. - beam_number_each_period : BeamNumberEachPeriod An instance containing different acquisition cycles, including initial_cycle and end_cycle fields. - beam_name2number : list of SteeringVelocity each contains a beam name and its respective steering velocity.

Read a timeline table XML file and parse its contents into a TimeLine object.

Read a swath table XML file and returns a SwathTable object.

Parameters:

Name Type Description Default
filename str or Path

Path to the XML file containing the swath parameter table.

 required

Returns:

Type Description
SwathTable

Parsed data representing the swath table, including beam ID, frequency sampling, and parameter periods.

Read a trajectory XML file and parse its contents into a Trajectory object.

The trajectory file can be in either GSS or RDB format.

Parameters:

Name Type Description Default
filename Path

Path to the XML file containing the trajectory data.

 required
traj_format TrajectoryFormat

Format of the XML file: possible values "GSS" or "RDB".

 'GSS'

Returns:

Type Description
Trajectory

Parsed trajectory data as a Trajectory object.

Raises:

Type Description
ValueError

If the provided trajectory format is not supported.
