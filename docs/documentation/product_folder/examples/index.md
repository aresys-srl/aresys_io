# Examples of Working with Product Folders

This section of the documentation provides _practical examples_ of how to work with Aresys Product Folders format.
The exercises are described step by step to illustrate the main features and functionalities of the format,
including how to read, create, write, and modify products.

The examples are intended to provide a general understanding of the recommended workflows and the main objects involved
when working with Product Folders. They _focus on code clarity and simplicity_ rather than performance optimization or
Python best practices, making it easier to understand each procedure and its underlying concepts.

The procedures presented throughout this section can be used as **indicative guidelines** for your own workflows.
You can also follow the exercises hands-on by downloading the sample data that is publicly available.
