# Aresys Formats Input/Output

**Aresys IO** is the official Python package for reading, writing and work with Aresys formats.

The supported internal formats are:

<div class="result" markdown>

:lucide-folder-kanban:{ .lg .middle } [__Product Folder__](documentation/product_folder/index.md#pf){ data-preview }

:lucide-crosshair:{ .lg .middle } [__Point Target Binary__](documentation/point_target/index.md#targets){ data-preview }

:lucide-satellite:{ .lg .middle } [__SAR System__](documentation/sarsystem/index.md#sarsys){ data-preview }

</div>

Each module is designed to be modular, independent and extensible, allowing users to adopt only the functionalities
they need.

## Tutorials

Each section of the documentation provides detailed usage guides and examples for the main features. Quickstart guides
are also available to help you get started with the package. Just run the code provided in your terminal and follow the
instructions!

## Getting Started

This package can be installed using ``pip`` in any python environment satisfying the requirements.

> :lucide-circle-chevron-right: Refer to the [installation documentation](install.md) for further information.
